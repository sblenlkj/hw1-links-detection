# Family-level finalizer tests

Эта директория содержит end-to-end тесты семейств документов через `LinksFinalizer`.

Цель этих тестов — проверить не отдельную регулярку или resolver изолированно, а полный путь:
candidate detection → segmentation → document resolution → finalization.

Тестовые ссылки собираются в один документ через `TestTextBuilder`, который добавляет нейтральный шум между вручную заданными юридическими ссылками. Поэтому тесты дополнительно проверяют, что соседние ссылки не склеиваются в один segment.

Этот файл фиксирует не только покрытые случаи, но и намеренно оставленные за пределами текущих тестов.

## code

Файл: `test_code_family.py`.

### Проверяем

- Полное название кодекса с вариантами окончания:
  - `Арбитражного процессуального кодекса Российской Федерации`;
  - `Арбитражного процессуального кодекса России`;
  - `Арбитражный процессуального кодекса РФ`.
- Короткие aliases:
  - `АПК России`;
  - `АПК РФ`;
  - `АПК`;
  - `КоАП РФ`.
- Несколько разных кодексов в одном тексте: АПК, ТК, КоАП.
- Форму `Кодекса Российской Федерации об административных правонарушениях`, где указание `Российской Федерации` находится внутри полного названия.
- Ссылку с дополнительной структурой документа: `ст. 11 п. 4 ...`.
- Наличие discourse-маркеров и нейтрального текста вокруг ссылок.
- Несколько последовательных ссылок в одном документе без их склеивания.

### Пока не проверяем

- Все 21 кодекса по отдельности.
- Все aliases каждого кодекса из исходного `law_aliases.json`.
- Все возможные падежные формы названий.
- Все комбинации `статья / пункт / часть / подпункт` — это отдельно покрывается структурными тестами.
- Неоднозначность между кодексами: в текущем наборе она специально не моделируется.

## presidential_order

Файл: `test_presidential_order_family.py`.

### Проверяем

- Все три базовых family aliases из storage:
  - `Распоряжение Президента`;
  - `Распоряжение`;
  - `РП`.
- Варианты полного family marker:
  - `Распоряжение Президента Российской Федерации`;
  - `Распоряжение Президента России`;
  - `Распоряжение Президента РФ`;
  - `Распоряжение Президента`.
- Морфологические формы `Распоряжения`, `Распоряжению`, `Распоряжением`.
- Разрешение документа по номеру вида `№34-рп`.
- Полную комбинацию family + number + date + quoted title.
- Разрешение по family + quoted title без номера.
- Неоднозначный title: один и тот же заголовок соответствует `law_id=38` и `law_id=40`; ожидается `ambiguous`, а не обычные links.
- Снятие неоднозначности одинакового title с помощью номера `№267-рп` / `№370-рп`.
- Несколько соседних распоряжений в одном шумовом документе и корректные границы segments.

### Пока не проверяем

- Все 34 распоряжения по отдельности.
- Все комбинации aliases, которые перечислены для каждого документа в исходном `law_aliases.json`.
- Разрешение распоряжения только по дате.
- Использование даты как самостоятельного disambiguator без номера/title.
- Поведение при неправильном или противоречивом сочетании number + date + title.
- Опечатки внутри family marker, номера, даты или title.
- Частичное совпадение title вместо точного quoted title.
- Варианты номера без `№` или без суффикса `-рп`, если они отсутствуют в исходных aliases.

## Итоговое покрытие семейств

Family-level finalizer tests теперь существуют для всех восьми семейств:

1. `code`;
2. `presidential_order`;
3. `federal_law`;
4. `presidential_decree`;
5. `fundamentals_of_legislation`;
6. `rf_law`;
7. `federal_accounting_standard`;
8. `accounting_regulation`.

Эти тесты проверяют representative end-to-end сценарии для каждого семейства, включая основные механизмы разрешения документов и реальные случаи ambiguity/disambiguation. Они не являются исчерпывающим перебором всех документов и aliases из law_aliases.json.
